Q1. What is the problem with synchronous programming?
Answer

In synchronous programming, tasks execute one after another. The next task cannot start until the current task finishes.

String user = getUser();      // 5 sec
String orders = getOrders();  // 4 sec

System.out.println(user);
System.out.println(orders);

getUser()  -> 5 sec
getOrders() -> 4 sec

Total = 9 sec
The main thread remains blocked while waiting for each operation to complete.

Key Points
Tasks execute sequentially.
Main thread waits for completion.
Resources aren't utilized efficiently.
Poor performance for independent operations.

Interview Summary
Synchronous programming blocks the current thread until a task completes, causing unnecessary waiting and increased execution time.

Q2. Why was Future introduced?
Answer

Future was introduced to support asynchronous execution.
Instead of executing a task in the main thread, we submit it to a thread pool.

ExecutorService executor =
        Executors.newFixedThreadPool(2);

Future<String> future =
        executor.submit(() -> {
            Thread.sleep(5000);
            return "Romil";
        });

System.out.println("Doing other work");
The task runs in another thread while the main thread continues execution.

Key Points
Supports asynchronous execution.
Allows parallel processing.
Main thread can do other work.
Result can be fetched later.

Interview Summary
Future allows a task to run asynchronously and provides a placeholder object to retrieve the result later.

Q3. What is Future in Java?
Answer
Future is an interface in the java.util.concurrent package representing the result of an asynchronous computation.
Future<String> future =
        executor.submit(() -> "Hello");
The result may not be available immediately.
String result = future.get();

Key Points
Represents future result.
Returned by ExecutorService.
Supports status checking.
Supports cancellation.

Interview Summary
Future is a container for the result of an asynchronous task.

Q4. What are the important methods of Future?
Answer
get()
future.get();
Returns result and blocks if necessary.

isDone()
future.isDone();
Checks completion.

cancel()
future.cancel(true);
Attempts cancellation.

isCancelled()
future.isCancelled();
Checks cancellation status.

Interview Summary
The most commonly used Future methods are get(), isDone(), cancel(), and isCancelled().

Q7. What is CompletableFuture?
Answer
CompletableFuture is a class used for asynchronous and non-blocking programming.

Package:
java.util.concurrent.CompletableFuture

Example:
CompletableFuture<String> future =
CompletableFuture.supplyAsync(
() -> "Romil");

Key Points
Introduced in Java 8.
Implements Future.
Implements CompletionStage.
Supports async pipelines.
Interview Summary

CompletableFuture enables asynchronous execution, transformation, composition, and combination of tasks.

Q9. How do you create a CompletableFuture?
Answer
Using supplyAsync().

CompletableFuture<String> future =
CompletableFuture.supplyAsync(
() -> "Romil");

Using runAsync().

CompletableFuture<Void> future =
CompletableFuture.runAsync(
() -> System.out.println("Running"));

Key Points
supplyAsync()
Supplier<T>
Returns value.

runAsync()
Runnable
Returns nothing.

Interview Summary

supplyAsync() is used when a value must be returned, while runAsync() is used for fire-and-forget tasks.
